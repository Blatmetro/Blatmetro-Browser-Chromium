# Blatmetro Browser

**Версия исходного проекта:** 0.4.7 (разработка) · **Платформа:** Windows x64 · **Технологии:** C#, WPF, .NET 10, CefSharp.Wpf.NETCore 154.0.340, Chromium

Blatmetro Browser — настольный браузер для Windows. Текущая версия проекта сохраняет WPF-интерфейс и встроенный Chromium через CefSharp.

## Возможности

- Вкладки, адресная строка и поиск через DuckDuckGo, Google, Bing, Brave Search, Яндекс, Ecosia, Qwant, Startpage, Yahoo, PrivacyWall, Perplexity и Mail.Ru.
- Навигация назад и вперёд, перезагрузка, остановка загрузки и локальная страница новой вкладки.
- Закладки с локальным сохранением.
- Менеджер загрузок с прогрессом, отменой и открытием завершённых файлов. Список загрузок сохраняется между запусками; незавершённые при закрытии показываются как прерванные.
- Системная, светлая и тёмная темы; сайты получают значение `prefers-color-scheme`.
- Масштаб страницы, полноэкранный режим и сочетания клавиш `Ctrl+T`, `Ctrl+W`, `Ctrl+L`, `Ctrl+R`, `Ctrl+Tab`, `Ctrl+Shift+Tab`, `F5`, `F11` и `Esc`.
- Одновременно запускается один экземпляр браузера. Повторный запуск сообщает об открытом окне и пытается вывести его на передний план.

Полноценная история посещений, синхронизация, расширения и встроенное обновление не реализованы. Пункт истории в меню пока отключён. Система расширений не входит в версию 0.4.7.

## Данные и приватность

- Профиль Chromium, кэш и журнал CefSharp: `%LOCALAPPDATA%\Blatmetro\Browser`.
- Закладки, настройки и история загрузок: `%APPDATA%\Blatmetro\Browser` (`bookmarks.json`, `settings.json`, `downloads.json`). Настройки и закладки сохраняют форматы предыдущих версий.
- Файлы загрузок сохраняются в системную папку Windows «Загрузки».

История загрузок содержит имена файлов, пути, статусы и объём переданных данных. История посещений сайтов приложением не ведётся; отдельной политики очистки и срока хранения истории посещений пока нет. Логи CefSharp настроены на уровень предупреждений. Некоторые фоновые сетевые компоненты Chromium отключены, но это само по себе не доказывает отсутствие всех фоновых запросов.

## Требования и запуск

- Windows 10 x64 или новее.
- .NET 10 SDK.
- Доступ к NuGet для восстановления CefSharp при первой сборке.

Из каталога проекта:

```powershell
dotnet restore .\BlatmetroBrowser.csproj -r win-x64
dotnet run --project .\BlatmetroBrowser.csproj -c Release -r win-x64 --no-restore
```

Сборка без публикации:

```powershell
dotnet build .\BlatmetroBrowser.csproj -c Release -r win-x64 --no-restore
```

`build.cmd` выполняет restore и self-contained publish для Windows x64 в `publish\win-x64`. Для создания установщика требуется Inno Setup 6; после публикации выполните `ISCC.exe BlatmetroBrowser.iss`. Готовый пакет появится в `installer-output`.

## Разработка и проверка

Проект использует CefSharp SelfHost: `Program.cs` обрабатывает дочерние процессы CEF до запуска WPF. На целевой Windows-системе необходимо проверить сборку и поведение WPF/CEF, включая вкладки, загрузки, сохранение данных и полноэкранный режим.
