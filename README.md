# Blatmetro Browser

**Blatmetro Browser** — настольный веб-браузер для Windows, разрабатываемый в рамках проекта Blatmetro.

Проект направлен на создание собственного браузера с удобным интерфейсом, современными веб-технологиями и постепенно расширяющимся набором возможностей.

Браузер создаётся с использованием C#, WPF, .NET и Chromium через CefSharp. В процессе разработки активно применяются инструменты искусственного интеллекта.

## 🌐 О проекте

Blatmetro Browser — независимый проект браузера, который разрабатывается под брендом Blatmetro.

Главная идея проекта — создать собственный браузер для Windows, постепенно развивая его функциональность, интерфейс, производительность и безопасность.

Разработка ведётся поэтапно. Каждая новая версия может содержать новые возможности, улучшения существующих функций и исправления обнаруженных проблем.

Blatmetro Browser использует браузерный движок Chromium через библиотеку CefSharp.

**Цели проекта:**
- Создание собственного настольного браузера.
- Разработка удобного и понятного пользовательского интерфейса.
- Интеграция современных веб-технологий.
- Постепенное расширение функциональности.
- Повышение стабильности и безопасности.
- Создание собственной экосистемы программного обеспечения Blatmetro.

## ✨ Основные возможности

В актуальной ветке разработки предусмотрены следующие функции:

### 🌍 Просмотр веб-страниц
- Открытие сайтов в интернете.
- Навигация по страницам.
- Переход назад и вперёд.
- Обновление страниц.
- Адресная строка.
- Поиск в интернете.

### 📑 Управление вкладками
- Создание новых вкладок.
- Переключение между вкладками.
- Работа с несколькими веб-страницами одновременно.

### 🔖 Закладки
- Добавление сайтов в закладки.
- Сохранение закладок между запусками.
- Хранение пользовательских данных в JSON.

### 📥 Загрузки
- Отдельная страница загрузок.
- Отображение прогресса загрузки.
- Сохранение истории загрузок.
- Отображение статусов загрузок.
- Выбор системной папки загрузок.
- Обработка ошибок загрузки.

### 🎨 Внешний вид
- Светлая тема.
- Тёмная тема.
- Системная тема.
- Изменение масштаба веб-страниц.
- Полноэкранный режим.

### ⚙️ Дополнительные возможности
- Выбор поисковой системы.
- Поддержка горячих клавиш.
- Работа с контекстными меню Chromium.
- Повторный запуск браузера с поиском уже открытого окна.

Набор возможностей может изменяться в последующих версиях.

## 📦 Установка

1. Откройте раздел Releases данного репозитория.
2. Найдите необходимую версию Blatmetro Browser.
3. Перейдите к разделу Assets.
4. Скачайте установочный файл.
5. Запустите установщик.
6. Следуйте инструкциям мастера установки.
7. После завершения установки запустите Blatmetro Browser.

Перед установкой новой версии рекомендуется сохранить важные пользовательские данные.
