Blatmetro Browser 0.4.7 — заметки для сборки и проверки

Это исходный проект версии 0.4.7. Для установщика используется Inno Setup 6.

Требования: Windows x64 и .NET 10 SDK. CefSharp.Wpf.NETCore 154.0.340.

Восстановление пакетов и сборка:
  dotnet restore .\BlatmetroBrowser.csproj -r win-x64
  dotnet build .\BlatmetroBrowser.csproj -c Release -r win-x64 --no-restore

Подготовка автономной публикации и установщика:
  build.cmd
  ISCC.exe BlatmetroBrowser.iss

Публикация помещается в publish\win-x64, установщик — в installer-output.
Установщик рассчитан на Windows x64 и устанавливает приложение в профиль
текущего пользователя. Для его компиляции должен быть установлен Inno Setup 6.

Ручная проверка на Windows:
  - запуск браузера и повторный запуск при уже открытом экземпляре;
  - создание, переключение, закрытие последней и обычной вкладки;
  - переход по ссылке, всплывающее окно, возврат из полноэкранного режима;
  - поиск с новой вкладки и проверка, что сообщения с веб-страниц не выполняют команды;
  - загрузка файла, совпадающее имя, отмена, завершение и список после перезапуска;
  - сохранение и повторная загрузка settings.json и bookmarks.json предыдущей версии;
  - восстановление JSON из .bak после повреждения основного файла;
  - проверка уровня CEF-лога и аппаратного ускорения на поддерживаемой системе.

Профиль Chromium и лог CefSharp находятся в:
  %LOCALAPPDATA%\Blatmetro\Browser

Настройки, закладки и история загрузок находятся в:
  %APPDATA%\Blatmetro\Browser

В этой версии нет отдельной истории посещений. Пункт меню истории отключён.
